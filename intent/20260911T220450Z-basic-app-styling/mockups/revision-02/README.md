## Design changes from revision 01

- Removed the large index-page hero and lead copy.
- Moved **Create post** into the authenticated navigation bar.
- Replaced post cards with a compact, Hacker News-inspired list.
- Index entries contain only `title (url)`, comment count, author, date, and owner actions; they do not show post bodies.
- Kept the cool paper / ink / enamel-blue direction and the comment-depth rail for the post detail screen.

The mockups use system fonts only; they are design inputs and do not authorize implementation.
